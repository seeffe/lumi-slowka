# Lumi Słówka — приложение для изучения английских слов (для сестры 6–7 лет)

## Что это
PWA (веб-приложение, которое ставится на телефон иконкой). Ребёнок учит английские слова с польского.
Устройство: Google Pixel 8a (Android, Chrome), интернет всегда есть.
Владелец проекта — Максим (новичок в программировании): объясняй ему всё простым языком, по-русски.

## Файлы
- `index.html` — ВСЁ приложение в одном файле (HTML + CSS + JS, без библиотек и без сборки).
- `manifest.webmanifest` — описание для установки на телефон (имя, иконка, цвета).
- `sw.js` — service worker: кэш, чтобы открывалось быстро и без сети.
- `icon-192.png`, `icon-512.png` — иконки (персонаж Lumi).

## Как устроено (index.html)
- `RAW` — список слов: `английский|польский|картинка|тема`. Картинка = эмодзи, `#цвет` (кружок цвета) или число.
  Новое слово добавлять просто строкой в RAW.
- `ORDER` — порядок изучения: темы по очереди, чтобы было разнообразно.
- Состояние хранится в `localStorage` под ключом `lumi_slowka_v1` (объект `S`).
- Интервальное повторение (коробки Лейтнера): `box` 1..5, интервалы `INTERVAL=[0,1,2,4,7,14]` дней. box ≥ 4 = «выучено».
- Голос: `speechSynthesis` (Google-голоса en-US и pl-PL на Android). Распознавание: `webkitSpeechRecognition`, lang `en-US`.
- Распознавание у детей слабое, поэтому **засчитывается любая попытка** сказать слово (звезда +1), точное совпадение даёт +2. Не делать строже: ребёнок бросит.
- Урок (`startSession`): новые слова (`S.perDay`, по умолчанию 5) → знакомство (`intro`) → игра → повторение старых слов в случайной игре (`pick`, `balloons`, `yesno`, `say`) → иногда `memory` → подарок-наклейка.
- Игры урока также: `feed` («Покорми Lumi»: перетащить предмет Lumi в рот; только темы из `FEEDABLE`, остальные слова уходят в `pick`) и `talk` (мини-диалоги из `TALKS` + вопросы по выученным словам в `talkSet`; любая попытка засчитывается, ключевое слово = +2).
- Знакомство (`onboard`) при первом запуске: имя ребёнка (`S.kid`, микрофон pl-PL или ввод), цвет Lumi (`S.color` → `COLORS`), имя Lumi (`S.name`). Похвала по имени: `kidC()`.
- Карта (`mapScreen`, `travel`): `S.trip` = шаги, 1 урок = 1 шаг, `STEPS` шагов на остров из `ISLANDS`. Слова, выученные на острове, хранятся в `S.isl`.
- Диплом за неделю (`diploma`, `weekData`) из журнала `S.log`, сам показывается раз в 7 дней после урока.
- Звук: громкость `S.vol` (кнопка 🔊, 3 уровня), тихая фоновая мелодия `MEL` (`S.music`: кнопка 🎵/🔕 в верхней строке рядом с 🔊 или у родителей), во время речи тише, во время микрофона молчит. Танец Lumi после 3 правильных подряд (`combo`).
- **1 урок в день** (потом Lumi «спит»). Родитель может разрешить ещё один урок.
- Экран для родителей: удерживать ⚙️ 2 секунды (на русском).
- Награды: звёзды → шапки для Lumi (`HATS`), наклейки (`STICKERS`) после каждого урока.

## Правила
- Тёмная тема. Всё, что слышит и видит ребёнок, на польском, слова на английском. Экран для родителей на русском.
- Персонаж Lumi — наш собственный (SVG в `lumiHTML`). Не копировать Buddy.ai: ни их персонажа, ни имени, ни звуков, ни картинок.
- После изменений в `index.html` или других файлах поднимать версию `CACHE` в `sw.js` (`lumi-v1` → `lumi-v2`), иначе телефон может показывать старую версию.
- Микрофон в Chrome работает только по HTTPS (GitHub Pages подходит) или на localhost.
