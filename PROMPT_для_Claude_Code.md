# Что вставить в Claude Code

1. Положи все файлы из этой папки (`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `CLAUDE.md`) в отдельную папку, например `E:\Max\Scripts\ClaudeCode\LumiSlowka`.
2. Открой Claude Code в этой папке.
3. Вставь текст ниже целиком.

---

Привет! В этой папке готовое веб-приложение Lumi Słówka для моей сестры (6–7 лет): она учит английские слова с польского. Сначала прочитай CLAUDE.md. Объясняй мне всё как абсолютному новичку, по-русски.

Задача: опубликовать приложение в интернете, чтобы мама открыла его на своём Pixel 8a и поставила иконкой на главный экран. Микрофону нужен HTTPS, поэтому используем GitHub Pages (бесплатно).

Шаги:
1. Проверь, что установлены `git` и `gh` (GitHub CLI) и что я вошёл в GitHub (`gh auth status`). Если чего-то нет, скажи, какую команду запустить, и подожди меня.
2. Сделай здесь git-репозиторий, первый коммит и **публичный** репозиторий на GitHub под названием `lumi-slowka` (Pages бесплатно работает только для публичных репозиториев, а секретов в коде нет).
3. Включи GitHub Pages из ветки `main`, корневая папка (`gh api` → `repos/{owner}/lumi-slowka/pages`). Дождись, пока сайт откроется, и дай мне ссылку вида `https://<логин>.github.io/lumi-slowka/`.
4. Проверь, что по ссылке открываются `index.html`, `manifest.webmanifest`, `sw.js` и обе иконки (код ответа 200).
5. Напиши мне короткую инструкцию для мамы, как поставить приложение на Pixel 8a:
   Chrome → открыть ссылку → ⋮ → «Добавить на главный экран / Установить приложение» → при первом нажатии на 🎤 разрешить микрофон → громкость медиа повыше.
6. Объясни, как я буду обновлять приложение потом: меняем файлы → поднимаем `CACHE` в `sw.js` → `git commit` + `git push` → через 1–2 минуты обновится у мамы.

Ничего в логике приложения пока не меняй, сначала только публикация.
